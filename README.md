🌐 xSim – Global Connectivity Redefined 🚀
xSim is a next-generation e-SIM mobile application built with Flutter, designed to eliminate borders for the modern traveler. We’ve stripped away the complexity of traditional carriers and high roaming fees to make the world more accessible, one digital connection at a time.

✨ Key Features

🌎 Borderless Connectivity: High-speed, seamless internet access for travelers across Europe, the Middle East, and beyond.

⚡ Frictionless UX: Say goodbye to tedious forms. Our "Guest Checkout" flow creates accounts automatically in the background for a lightning-fast experience.

💎 Premium Aesthetic: A sophisticated UI inspired by luxury travel, featuring a custom Cyprus Green (#004643) and Cream (#F0EDE5) palette.

💸 Budget-Friendly: Offering the most competitive prices in the market, specifically tailored for travelers flying from Turkey to the world.

🛠️ Robust Engineering: High-performance cross-platform execution on both iOS and Android via the Flutter framework.

🛠 Technical Stack

📱 Framework: Flutter (Dart).

🎨 Design System: Custom Brand Identity (Cyprus Green & Cream).

🏗 Architecture: Clean, scalable, and maintainable codebase.

🤖 Automation: Smart daily progress tracking integrated directly with this repository.
