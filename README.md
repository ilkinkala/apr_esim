### 📖 Overview
**xSim** is a next-generation e-SIM mobile application built with **Flutter**, designed to eliminate borders for the modern traveler. We’ve stripped away the complexity of traditional carriers to make the world more accessible, one digital connection at a time.

---

### ✨ Key Features

- 🌎 **Borderless Connectivity**: High-speed internet access for travelers across Europe, the Middle East, and beyond.
- ⚡ **Frictionless UX**: Our "Guest Checkout" flow creates accounts automatically in the background for a lightning-fast experience.
- 💎 **Premium Aesthetic**: A sophisticated UI featuring a custom **Cyprus Green (#004643)** and **Cream (#F0EDE5)** palette.
- 💸 **Budget-Friendly**: Competitive prices specifically tailored for travelers flying from Turkey to the world.
